Pin Map:
* Pin 18 is an LED Output pin turns ON/OFF on short button press
* Pin 27 is an Buzzer Output pin that beeps on long button press (≥2 sec)
* Pin 33 is a Button Input pin that detects short or long press
* Pin 21  is a I²C SDA pin that is Data line for OLED display
* Pin 22 is a	I²C SCL	Clock used for OLED display
* 3.3V & GND are Power & Ground respectivly where power supply for OLED and other components

Summary:
When the button is pressed shortly, the LED toggles ON/OFF. When the button is held for 2 seconds or more, the buzzer beeps. The OLED display shows what action happened (like “LED ON” or “Buzzer Tone”).
